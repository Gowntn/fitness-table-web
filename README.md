# 健身Excel超级套表 · 手机网页版

> 内容源自 B 站 UP 主「好人松松」制作的《健身Excel超级套表》

> 代码由 DeepSeek V4 Flash 生成

## 这是什么

原来是一套 Excel 表格，专门帮你算"每天该吃什么、吃多少"。
现在把它做成了**手机网页**：手机浏览器打开就能用，不用装软件、不用学 Excel、不用注册登录。

## 能做什么

- **饮食计算器**：填上性别、年龄、身高、体重，自动算出每天该吃多少碳水、蛋白质，每一顿吃多少克，每样食物称多少克（力训日/休息日分开算）
- **减脂/增肌问答**：常见问题（体重不掉怎么办、吃外卖怎么办……）的答案都在里面
- **食物营养率**：查各种食物的碳水率、GI 值，还能搜索
- **有氧消耗**：按心率和运动项目，查每小时消耗多少大卡
- **训练计划**：健身房三分化、四分化、居家训练的动作安排和组数
- **最大力量预测**：输入你做组的配重和次数，预测你的 1RM
- **拉伸与解剖图谱**：看图了解肌肉、关节和拉伸动作

## 怎么用

手机或电脑浏览器直接打开即可。
